# Локальная копия документации Telegram

Снято 2026-10-06. Это снимок: если факт критичен, сверяй с сайтом.

- `official/webapps.md` — Mini Apps, https://core.telegram.org/bots/webapps
- `official/api.md` — Bot API, https://core.telegram.org/bots/api (большой файл, ищи через grep)
- `official/features.md` — возможности ботов, https://core.telegram.org/bots/features
- `tma-js/` — документация SDK tma.js и описание платформы, исходники сайта
  docs.telegram-mini-apps.com (репозиторий Telegram-Mini-Apps/tma.js, коммит 534e6f6 от 2026-07-14)
- `tma-llms-full.txt` — сторонняя шпаргалка для LLM, https://github.com/ohld/tma-llms-txt

В файлах `official/` подчёркивания экранированы: ищи `chat\_instance`, а не `chat_instance`.
