# Этап 6: чат стола и реакции

Спецификация: разделы 2.6, 2.7.

## Решения

- Сообщения чата и реакции идут только через сокет и нигде не сохраняются: сервер проверяет и сразу рассылает тем, у кого открыт стол.
- Чат: текст после обрезки пробелов — от 1 до 200 символов; писать может любой, у кого открыт стол (в том числе зритель).
- Реакции: только сидящим; значение — одно из восьми эмодзи. Формат `{ kind: 'emoji', value }` оставляет место для кастомных эмодзи.
- Клиент хранит сообщения, пока открыт экран стола; реакция гаснет через 3 секунды по таймеру клиента.
- Чат открывается кнопкой в шапке стола; на кнопке — счётчик непрочитанных.

## Файлы

- `shared/src/index.ts` — набор реакций, лимиты, типы событий.
- `server/src/rooms.ts` — `tableOf`, `isSeatedAt`; `server/src/realtime.ts` — события `chat:send`, `reaction:send`.
- `client/src/realtime.ts`, `client/src/screens/Table.tsx`, `table.css`.
- Тесты: `server/test/realtime.test.ts`.

## Проверка руками

Две вкладки: сообщение и реакция из одной видны в другой; после выхода и входа чат пуст.
